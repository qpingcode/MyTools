# MyToolsDesktop

一个使用.NET 8.0框架开发的WPF桌面工具集应用程序。

## 项目信息

- 框架: .NET 8.0 Windows
- 项目类型: WPF (Windows Presentation Foundation)
- 默认开发语言: C#

## 如何运行

在项目目录中，使用以下命令运行应用程序:

```
dotnet run
```

## 功能

- 基本WPF应用程序框架
- 使用XAML开发用户界面
- 支持现代Windows应用程序功能
- 用户信息管理
- 应用程序设置
- 系统托盘功能，关闭窗口时最小化到托盘
- 开机自启动设置选项
- 单实例应用程序，防止多个实例同时运行
- 全局热键快速搜索功能
- 可自定义快捷键设置
- 实时搜索结果显示

## 快速搜索功能

- 使用默认快捷键 `Alt+L` 随时打开搜索窗口
- 输入内容即时显示搜索结果
- 支持键盘导航搜索结果
- 可自定义搜索快捷键

## 开发环境要求

- .NET 8.0 SDK
- Visual Studio 2022或更高版本（推荐）或Visual Studio Code与C#扩展
- Windows操作系统
